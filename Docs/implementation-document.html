1. Environment Prerequisites

  • Runtime & SDK: .NET 8.0 SDK (version 8.0.x or higher).
  • Operating System: Windows 10/11, macOS, or Linux.
  • Web Browser: Any modern browser (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
  • Optional: Visual Studio 2022, VS Code with C# Dev Kit, or JetBrains Rider.

Verify your .NET installation by executing:

dotnet --version

3. Configuration & HTTP Pipeline (Program.cs)

The HTTP request pipeline is structured to seamlessly serve API requests under /api/* and fallback to the React 18 SPA for client-side routing: 

// Program.cs Pipeline Configuration
var app = builder.Build();

if (app.Environment.IsDevelopment())
{
    app.UseSwagger();
    app.UseSwaggerUI(c => {
        c.SwaggerEndpoint("/swagger/v1/swagger.json", "ABC Pharmacy API v1");
        c.RoutePrefix = "swagger";
    });
}

app.UseCors("AllowAll");

// Serves default index.html and static files from wwwroot
app.UseDefaultFiles();
app.UseStaticFiles();

app.UseRouting();
app.UseAuthorization();

app.MapControllers();

// Single Page Application Fallback
app.MapFallbackToFile("index.html");

app.Run();

4. Data Initialization & JSON Storage

When the application starts for the first time, PharmacyService verifies the existence of the Data/ directory and initializes seed datasets:

  • Data/medicines.json: Pre-populated with 8 diverse medicines showcasing:
    • Expiring in < 30 days (Red): Amoxicillin (+14 days), Ibuprofen (+22 days).
    • Low stock < 10 units (Yellow): Metformin (6 units), Lisinopril (8 units).
    • Both Red & Yellow (Dual): Azithromycin (+9 days, 4 units).
    • Standard (Normal): Paracetamol, Cetirizine, Omeprazole.
  • Data/sales.json: Pre-populated with initial sales transactions to immediately display historical data on the Sales Records tab.

5. Production Packaging & Dockerization

5.1 Self-Contained Release Build

To compile an optimized production distribution:

dotnet publish -c Release -o ./publish

5.2 Docker Containerization

A multi-stage Dockerfile allows portable containerized deployment on any cloud host:

# Multi-stage Dockerfile
FROM mcr.microsoft.com/dotnet/sdk:8.0 AS build
WORKDIR /src
COPY ["ABCPharmacy.csproj", "./"]
RUN dotnet restore "ABCPharmacy.csproj"
COPY . .
RUN dotnet publish "ABCPharmacy.csproj" -c Release -o /app/publish

FROM mcr.microsoft.com/dotnet/aspnet:8.0 AS final
WORKDIR /app
COPY --from=build /app/publish .
EXPOSE 8080
ENV ASPNETCORE_URLS=http://+:8080
ENTRYPOINT ["dotnet", "ABCPharmacy.dll"]

6. Troubleshooting & Diagnostics

  • Port 5160 Already In Use: Update Properties/launchSettings.json and change applicationUrl to another free port (e.g. http://localhost:5200), or launch with: 
    dotnet run --urls "http://localhost:5200"
  • Resetting Demo Data: To revert to the clean initial seed state, delete the Data/medicines.json and Data/sales.json files and restart the application; PharmacyService will automatically regenerate fresh seed data.
  • React Browser Cache: Perform a hard browser reload (Ctrl + F5 or Cmd + Shift + R) to ensure freshly updated React component bundles are loaded into memory.
