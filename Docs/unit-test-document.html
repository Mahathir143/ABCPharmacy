1. Testing Strategy & Objectives

The quality assurance strategy for ABC Pharmacy verifies end-to-end functionality across both the .NET 8 Web API backend and the React 18 Single Page Application frontend:

  • Backend Unit Testing (xUnit): Verifies business rules inside PharmacyService (stock checks, total bill calculations, SemaphoreSlim concurrency serialization) and validation attributes inside API controllers.
  • React Component State Testing: Tests state changes triggered by user actions (search filter updates, modal open/close, real-time stock deductions upon sale confirmation).
  • Boundary Value Analysis: Tests critical date boundaries (29 days vs 30 days vs 31 days) and stock boundaries (9 units vs 10 units vs 0 units).
  • Concurrency & Data Integrity: Asserts that rapid, concurrent sales reject overselling and never corrupt medicines.json or sales.json.

3. Automated C# Unit Test Suite (xUnit)

The following automated test suite can be included in a test project (ABCPharmacy.Tests) to verify the service layer:

using Xunit;
using ABCPharmacy.Models;
using ABCPharmacy.Services;
using Microsoft.AspNetCore.Hosting;
using Moq;

namespace ABCPharmacy.Tests;

public class PharmacyServiceTests : IDisposable
{
    private readonly string _testDir;
    private readonly PharmacyService _service;

    public PharmacyServiceTests()
    {
        _testDir = Path.Combine(Path.GetTempPath(), "ABCPharmacy_Tests_" + Guid.NewGuid().ToString("N"));
        Directory.CreateDirectory(_testDir);

        var mockEnv = new Mock<IWebHostEnvironment>();
        mockEnv.Setup(m => m.ContentRootPath).Returns(_testDir);

        _service = new PharmacyService(mockEnv.Object);
    }

    [Fact]
    public async Task AddMedicine_ValidEntity_ShouldPersistSuccessfully()
    {
        // Arrange
        var med = new Medicine
        {
            FullName = "Amoxicillin 500mg",
            Brand = "GSK",
            ExpiryDate = DateTime.Today.AddDays(20),
            Quantity = 50,
            Price = 12.50m
        };

        // Act
        var result = await _service.AddMedicineAsync(med);

        // Assert
        Assert.NotNull(result.Id);
        var retrieved = await _service.GetMedicineByIdAsync(result.Id);
        Assert.NotNull(retrieved);
        Assert.Equal("Amoxicillin 500mg", retrieved.FullName);
    }

    [Fact]
    public async Task RecordSale_SufficientStock_ShouldDecrementStockAndLogSale()
    {
        // Arrange
        var med = await _service.AddMedicineAsync(new Medicine
        {
            FullName = "Paracetamol 500mg",
            Brand = "Panadol",
            Quantity = 20,
            Price = 5.00m,
            ExpiryDate = DateTime.Today.AddDays(100)
        });

        var saleDto = new CreateSaleDto
        {
            MedicineId = med.Id,
            Quantity = 4,
            CustomerName = "Jane Doe"
        };

        // Act
        var sale = await _service.RecordSaleAsync(saleDto);

        // Assert
        Assert.Equal(20.00m, sale.TotalPrice); // 4 * 5.00
        var updatedMed = await _service.GetMedicineByIdAsync(med.Id);
        Assert.Equal(16, updatedMed!.Quantity); // 20 - 4
    }

    [Fact]
    public async Task RecordSale_InsufficientStock_ShouldThrowInvalidOperationException()
    {
        // Arrange
        var med = await _service.AddMedicineAsync(new Medicine
        {
            FullName = "Inhaler",
            Brand = "Ventolin",
            Quantity = 2,
            Price = 30.00m,
            ExpiryDate = DateTime.Today.AddDays(200)
        });

        var saleDto = new CreateSaleDto
        {
            MedicineId = med.Id,
            Quantity = 10 // Requests more than available (2)
        };

        // Act & Assert
        await Assert.ThrowsAsync<InvalidOperationException>(() => _service.RecordSaleAsync(saleDto));
    }

    public void Dispose()
    {
        if (Directory.Exists(_testDir))
        {
            Directory.Delete(_testDir, true);
        }
    }
}

4. Manual Assessment Verification Script

Step-by-step instructions for live evaluators to verify the requirements via UI:

  1. Launch Application: Run dotnet run in the terminal and open http://localhost:5160.
  2. Verify Red Highlight: Locate "Amoxicillin" and "Ibuprofen" in the grid. Confirm they have a soft red background with a badge stating < 30d Expiry.
  3. Verify Yellow Highlight: Locate "Metformin" (Qty 6) and "Lisinopril" (Qty 8). Confirm they have a yellow background with a badge stating < 10 In Stock.
  4. Verify React Live Search: Type ibu into the search box. Confirm the grid dynamically narrows down exclusively to "Ibuprofen" without a page reload.
  5. Verify Add Medicine: Click "+ Add Medicine", fill in details, and save. Confirm the medicine instantly appears at the top of the grid.
  6. Verify Sale Deduction: Click the "Sell" button on a medicine with 5 units. Sell 2 units. Confirm stock immediately drops to 3 and the row turns yellow (since 3 < 10).
  7. Verify Sales Records: Switch to the "Sales Records" tab. Confirm the new sale appears with accurate timestamp, unit price, and total bill.
