📋 Project Overview & Evaluation Highlights

This documentation portal accompanies the engineering submission for Client ABC Pharmacy. Engineered by a .NET + React.js Full Stack Developer, the system provides real-time medicine inventory tracking with business-rule color coding, Point-of-Sale (POS) sale records management with atomic stock deductions, and server-side JSON persistence.
